# مختبر الكيمياء

تطبيق تعليمي عربي/إنجليزي مبني بواجهة React وTypeScript وVite، ومغلّف كتطبيق Android عبر Capacitor. الواجهة متجاوبة للهواتف والأجهزة اللوحية، والحد الأدنى المستهدف Android 8 (API 26). يعمل المحتوى التعليمي محلياً دون اعتماد على خطوط أو محتوى ويب خارجي.

## ما يتضمنه التطبيق

- تصميم عربي RTL وإنجليزي LTR، مع تبديل اللغة مباشرة من الإعدادات.
- وضع نهاري وليلي، وتحكم بحجم النص من 90% إلى 130%، محفوظ محلياً.
- ستة دروس ثنائية اللغة موسعة: الذرة والأيونات، حالات المادة، الأحماض والقواعد، الاتزان، المول والحسابات، والروابط الكيميائية.
- كل درس يضم تمهيداً وأهدافاً وخريطة مفاهيم وشرحاً متدرجاً وعلاقة علمية ومثالاً محلولاً ومقارنة وتطبيقات ومفهومًا شائعاً واختباراً وخلاصة ومصطلحات.
- محاكاة تفاعلية آمنة مختلفة بحسب موضوع الدرس.
- مسار مستقل من ثماني مراحل عن الذهب والجيولوجيا يركز على الملاحظة والتحقق والسلامة والبيئة، ولا يقدم إجراءات استخلاص.
- معجم ثنائي اللغة قابل للبحث ومرتبط بالدروس.
- تقدّم الدروس والمحفوظات محفوظة على الجهاز فقط، دون حساب.
- ألوان وتلميحات بصرية متمايزة حسب القسم والموضوع، مع احترام إعداد تقليل الحركة.

## بناء الواجهة ومزامنتها مع Android

```sh
npm ci
npm run build
npx cap sync android
```

## بناء APK من GitHub Actions

يبدأ سير العمل `Build Chemistry Lab APK` تلقائياً بعد كل دفع إلى الفرع، أو يمكن تشغيله يدوياً من تبويب **Actions** ثم **Run workflow**. يستخدم JDK 21 وAndroid SDK API 35، ويرفع `app-debug.apk` كـArtifact باسم `chemistry-lab-debug-apk` لمدة 14 يوماً. نزّل الـArtifact بعد نجاح التشغيل، ثم فك ملف ZIP الناتج للحصول على APK.

## البناء المحلي

```sh
cd android
./gradlew assembleDebug
```

يتطلب البناء المحلي JDK كاملاً يتضمن `javac`، وAndroid SDK مع API 35 وBuild Tools 35.0.0. في البيئات التي لا تتوفر فيها هذه الأدوات، استخدم GitHub Actions.

المسار الناتج:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

`minSdkVersion` مضبوط على 26 (Android 8+)، وتُحفظ مخرجات الواجهة المضمنة في `android/app/src/main/assets/public` عند تشغيل `npx cap sync android`.
