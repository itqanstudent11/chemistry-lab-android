# مختبر الكيمياء العربي — APK دون إنترنت

هذا مشروع Android أصلي يغلف ملفات الدروس المحلية داخل WebView آمن نسبيًا باستخدام WebViewAssetLoader. لا يحتاج إلى إذن الإنترنت، وتُحفظ نتائج التعلم محليًا في بيانات التطبيق.

## البناء من الهاتف عبر GitHub
1. أنشئ مستودعًا **جديدًا** عامًا على GitHub باسم `chemistry-lab-android` (لا تستبدل مستودع الموقع القديم).
2. فك ضغط هذا المشروع، ثم ارفع **محتويات المجلد** إلى جذر المستودع. تأكد من ظهور المجلد `.github/workflows`، وملف `settings.gradle`، ومجلد `app`.
3. افتح تبويب **Actions**، واختر `Build offline Android APK` ثم **Run workflow**. يعمل البناء أيضًا تلقائيًا عند رفع الملفات إلى main.
4. انتظر اكتمال التنفيذ باللون الأخضر، وافتح التشغيل ثم قسم **Artifacts**، وحمّل `chemistry-lab-offline-apk.zip`.
5. فك ضغط artifact لتجد `app-debug.apk`، وثبته على أندرويد بعد السماح بالتثبيت من المصدر الذي تستخدمه.

> تنبيه: نسخة APK تجريبية بتوقيع تصحيح Debug، مناسبة للتجربة والتثبيت الشخصي، وليست نسخة متجر موقّعة بمفتاح نشر. قد يظهر تحذير أمني عند تثبيتها. لا تعطّل حماية الجهاز عمومًا.

## العمل دون إنترنت
ملفات HTML والصور مضمنة في APK ولا توجد تبعيات خارجية. استخدم التطبيق دون اتصال لاختبار الدروس والاختبارات. حفظ التقدم محلي ولا ينتقل تلقائيًا بين الأجهزة.
