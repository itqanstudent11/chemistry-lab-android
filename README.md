# مختبر الكيمياء — Android 4.0.0

تطبيق Kotlin وJetpack Compose يعمل محليًا، مبني على الفرع `native-v1` من [المشروع](https://github.com/itqanstudent11/chemistry-lab-android). هذه حزمة تعليمية محددة النطاق؛ ليست موسوعة أكاديمية مكتملة أو اعتمادًا مهنيًا.

## ما تتضمنه الحزمة

- منهج من 48 درسًا في أربعة مستويات، بالعربية والإنجليزية، مع أهداف ومتطلبات سابقة ومراجع وأمثلة محلولة و144 سؤالًا لكل لغة.
- فهارس حسب التخصص والمستوى، بحث، فهرس قابل للتنقل داخل الدرس والدليل، مفضلة وتقدم محفوظان على الجهاز. تُرحّل فهارس التقدم القديمة إلى معرّفات ثابتة، ويكتمل الدرس بعد الإجابة الصحيحة على جميع أسئلته. تُحفظ الإنجازات القديمة.
- جدول دوري بشبكة فعلية للمجموعات 1–18 والدورات 1–7، وسلسلتي اللانثانيدات والأكتينيدات، مع 118 عنصرًا وبحث باللغتين والرمز والعدد الذري. تميّز البيانات الوزن الذري النسبي عن العدد الكتلي لنظير مختار.
- سبعة نماذج وأدوات تعليمية: حفظ الذرات والمتفاعل المحدد، الذوبان الجسيمي، التخفيف، الغاز المثالي، وحموضة حمض قوي مخفف عند 25°C، وعارض هندسة جزيئية 3D قابل للتدوير، وموازنة آلية لمعادلات بصيغ متعادلة. جميع الحسابات تتحقق من المدخلات والوحدات والقيم غير المحدودة.
- معجم من 32 مصطلحًا بالعربية والإنجليزية مع بحث وإحالات للدروس والمراجع، ومظهر حسب النظام أو فاتح أو داكن، وتقليل الحركة.
- عشرة أدلة و41 موضوعًا بكل لغة عن جيولوجيا اليمن والذهب والمعادن والسلامة المهنية، إضافة إلى حاسبة محتوى الذهب النظري. لا تتضمن إجراءات استخلاص خطرة أو تعليمات تشغيل مواد سامة.
- اتجاه RTL للعربية وLTR للإنجليزية، واجهة قابلة للتمرير وتكبير خط النظام، وتسميات نصية للرسوم وعناصر التحكم. لم يُعتمد توافق شامل مع قارئات الشاشة.

## أمر التثبيت الموحد عبر Termux

نزّل **`chemistry-lab-4.0.0-final.zip`** إلى مجلد **Download**. امنح Termux الوصول إلى التخزين عبر `termux-setup-storage` مرة واحدة إذا لم تفعل سابقًا، ثم شغّل هذا الأمر الواحد:

```sh
pkg install -y unzip coreutils termux-tools && (set -eu; chemistry_bundle_dir="$(mktemp -d "$HOME/chemistry-lab-4.0.0.XXXXXX")"; unzip -q "$HOME/storage/downloads/chemistry-lab-4.0.0-final.zip" -d "$chemistry_bundle_dir"; bash "$chemistry_bundle_dir/chemistry-lab-4.0.0/install-termux.sh")
```

يفك الأمر الحزمة في مجلد جديد، ويتحقق من بصمة APK ثم يفتح مثبّت Android. وافق على التثبيت واسمح لـTermux بتثبيت التطبيقات من إعدادات Android عند طلبه. التثبيت يحتاج Android 7.0 أو أحدث؛ لا يبني Termux المصدر ولا يثبّت التطبيق بصمت.

تحتوي الحزمة على APK موقّع للتجربة، والمصدر كاملًا، و`SHA256SUMS`، وتقرير التحقق وأداة التثبيت. لا تتضمن مخزن مفاتيح خاصًا. بصمات الحزمة تكشف تغير الملفات، وليست إثبات هوية ناشر مستقلًا.

## حدود ومتطلبات لم تكتمل

- المحاكاة حسابات مثالية وعارض هندسي ثلاثي الأبعاد بأطوال نسبية؛ لا توجد حركية جزيئية معتمدة أو تنبؤ بتفاعلات عشوائية. الموازن يطبق حفظ الذرات على معادلات متعادلة ذات حل موجب وحيد النسبة، ولا يوازن الأيونات والهيدرات النقطية.
- لا توجد قياسات ميدانية أو عينات معتمدة تثبت الذهب في كعيدنة وكشر وبني قيس، ولا سجل محلي موثق لوجود كل عنصر في اليمن. لا تستنتج الاحتياطيات أو صلاحية التعدين من هذه المادة.
- يلزم تدقيق علمي وترجمي مستقل وتوسيع المنهج برسوم ومسائل إضافية قبل اعتباره مرجعًا موسوعيًا شاملًا. لا توجد مواصفات سابقة مستقلة داخل المستودع؛ نُفذ نطاق الأقسام المطلوبة والمحتوى المتاح.
- يلزم مفتاح إصدار ثابت لدى المالك للنشر والتحديث المستمر. توقيع التطوير الحالي قد يختلف عن نسخة قديمة، وعندها يرفض Android التحديث. إزالة التطبيق تمحو التقدم والمفضلة؛ لا يوجد تصدير للتقدم في هذا الإصدار.
- لم يُحسم توافق جميع الأجهزة وإصدارات Android أو إتاحة الوصول أو التراخيص اليمنية الحالية. يبيّن [تقرير التحقق](docs/VERIFICATION.md) الاختبارات المنفذة فعليًا وحدودها.

## البناء والتطوير

JDK 17، وAndroid SDK 35، وBuild Tools 35.0.0، وGradle Wrapper 8.10.2. من جذر المشروع:

```sh
./gradlew --no-daemon testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
python3 tools/validate_content.py
python3 tools/validate_elements.py
python3 scripts/test-installer.py
```

تشغيل اختبارات Android فعليًا يحتاج جهازًا أو محاكيًا: `./gradlew connectedDebugAndroidTest`. توليد الحزمة بعد إكمال التحقق: `python3 scripts/package-final.py`.
