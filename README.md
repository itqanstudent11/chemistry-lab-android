# مختبر الكيمياء

تطبيق تعليمي عربي من اليمين إلى اليسار، مبني بواجهة React وVite ومغلّف كتطبيق Android عبر Capacitor. التصميم متجاوب للهاتف واللوحي، والحد الأدنى المحدد للمشروع هو Android 8 (API 26). يعمل المحتوى الأساسي دون اتصال بالإنترنت.

## المزايا الموجودة

- واجهة رئيسية ومسارات للدروس والكيمياء والذهب والجيولوجيا.
- دروس تفاعلية تشمل شرحاً تدريجياً، خرائط مفاهيم، معادلات، مثالاً محلولاً، مقارنات، نشاطاً تفاعلياً، وأسئلة تفكير.
- مسار بصري من ثماني مراحل للذهب والجيولوجيا، بمحتوى آمن وتعليمي.
- معجم كيميائي قابل للبحث، وحفظ الدروس وتسجيل التقدم محلياً على الجهاز.
- واجهة RTL وألوان كريمية وتركوازية وذهبية، مع تنقل ملائم للشاشات الصغيرة.

## بناء الواجهة ومزامنتها إلى Android

```sh
npm install
npm run build
npx cap sync android
```

## بناء APK من Termux

بعد تجهيز بيئة Android/Gradle المتوافقة على Termux:

```sh
cd android
gradle assembleDebug
```

يوجد ملف APK الناتج في:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

الحد الأدنى مضبوط في `android/variables.gradle` إلى API 26. بعد تعديل الواجهة، شغّل `npm run build && npx cap sync android` ثم أعد بناء APK.
