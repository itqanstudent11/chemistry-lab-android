# مختبر الكيمياء — معاينة Kotlin الأصلية

هذه **معاينة تقنية أولى** وليست التطبيق الدولي النهائي. تحتوي على 10 دروس تمهيدية، اختبار واحد بنهاية كل درس، وقائمة قابلة للبحث لكل العناصر الـ118 (الرمز والعدد والكتلة التقريبية). لا يوجد قسم اختبارات مستقل. لا توجد محاكاة 3D بعد.

## التثبيت من Termux

1. انسخ ملف ZIP إلى Downloads وفكّه داخل مجلد منفصل.
2. أنشئ مستودع GitHub جديدًا فارغًا، ثم ارفع محتويات هذا المشروع إليه.
3. افتح Actions وشغّل Build Native Chemistry APK.
4. نزّل ملف artifact وثبّت APK.

## الأمان والتحديثات

معرّف هذه المعاينة `org.arabicchemistry.lab.nativeedition` لحماية تطبيقك السابق. توقيع debug في GitHub Actions غير ثابت عبر الأجهزة الافتراضية؛ لإصدارات قابلة للتحديث يلزم مفتاح توقيع ثابت ومحفوظ بأمان.

## تطوير لاحق مطلوب

- توسيع كل درس إلى منهج علمي شامل مع مراجع ورسوم ومسائل متعددة.
- ترتيب الجدول الدوري في شبكة فعلية وإضافة تفاصيل العنصر المعتمدة.
- حفظ التقدم في Room أو DataStore.
- بناء محاكاة علمية حقيقية واختبارات آلية وإتاحة الوصول.
- فحص جودة البناء وتجربة الأجهزة المختلفة.
