# مختبر الكيمياء

تطبيق تعليمي عربي/إنجليزي مبني بواجهة React وTypeScript وVite، ومغلّف كتطبيق Android عبر Capacitor. الواجهة متجاوبة للهواتف والأجهزة اللوحية، والحد الأدنى المستهدف Android 8 (API 26). يعمل المحتوى التعليمي محلياً دون اعتماد على خطوط أو محتوى ويب خارجي.

## ما يتضمنه التطبيق

- تصميم عربي RTL وإنجليزي LTR، مع تبديل اللغة مباشرة من الإعدادات.
- وضع نهاري وليلي، وتحكم بحجم النص من 90% إلى 130%، محفوظ محلياً.
- ستة دروس ثنائية اللغة موسعة: الذرة والأيونات، حالات المادة، الأحماض والقواعد، الاتزان، المول والحسابات، والروابط الكيميائية.
- كل درس يضم تمهيداً وأهدافاً وخريطة مفاهيم وشرحاً متدرجاً وعلاقة علمية ومثالاً محلولاً ومقارنة وتطبيقات ومفهومًا شائعاً واختباراً وخلاصة ومصطلحات.
- واجهة افتتاحية وصورة أصلية وهوية لونية خاصة بكل درس، محفوظة محلياً للعمل دون إنترنت.
- ست تجارب افتتاحية مستقلة البنية والتفاعل: مرصد للذرة، مسار لتحولات المادة، استوديو pH، غرفة اتزان، محطة حساب مول، واستوديو لقطبية الرابطة.
- لكل درس مخطط بصري وعناصر تحكم وملخص تفاعلي خاص بموضوعه؛ تبقى أدوات التنقل وفهرس القراءة متسقة لتقليل العبء المعرفي.
- خرائط مفاهيم تفاعلية؛ اختر العقدة لعرض الفكرة المرتبطة بها، مع دعم اللمس ولوحة المفاتيح.
- ستة مختبرات محاكاة مخصصة: سحابة احتمالية للذرة، منحنى تسخين بهضبتي التحول، مقياس pH لوغاريتمي، اتزان عكسي نوعي، حاسبة مول/جسيمات، وطيف قطبية الرابطة.
- كل محاكاة تعرض علاقة الحساب أو المتغيرات وحدود النموذج، وتوضح أنها تعليمية آمنة لا تتطلب مواد أو تجارب فعلية.
- مسار مستقل من ثماني مراحل عن الذهب والجيولوجيا يركز على الملاحظة والتحقق والسلامة والبيئة، ولا يقدم إجراءات استخلاص.
- معجم ثنائي اللغة قابل للبحث ومرتبط بالدروس.
- تقدّم الدروس والمحفوظات محفوظة على الجهاز فقط، دون حساب.
- واجهة علمية مشرقة بألوان مميزة حسب موضوع الدرس، مع وضع ليلي، تكبير الخط، دعم RTL/LTR واحترام إعداد تقليل الحركة.
- فهرس دروس تفاعلي يبرز القسم الحالي ويعرض تقدّم القراءة، ومسار مراحل جيولوجية قابل للتصفح على الهاتف.

## بناء الواجهة ومزامنتها مع Android

```sh
npm ci
npm run build
npx cap sync android
```

## بناء APK من GitHub Actions

يبدأ سير العمل `Build Chemistry Lab APK` تلقائياً بعد كل دفع إلى الفرع، أو يمكن تشغيله يدوياً من تبويب **Actions** ثم **Run workflow**. يستخدم JDK 21 وAndroid SDK API 35، ويرفع `app-debug.apk` كـArtifact باسم `chemistry-lab-v8-debug-apk` لمدة 14 يوماً. نزّل هذا الأثر تحديداً بعد نجاح التشغيل، ثم فك ملف ZIP الناتج للحصول على APK الإصدار 8.0.

## البناء المحلي

```sh
cd android
./gradlew assembleDebug
```

يتطلب البناء المحلي JDK كاملاً يتضمن `javac`، وAndroid SDK مع API 35 وBuild Tools 35.0.0. في البيئات التي لا تتوفر فيها هذه الأدوات، استخدم GitHub Actions.

المسار الناتج:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

`minSdkVersion` مضبوط على 26 (Android 8+). صور الدروس مضمنة محلياً بصيغة WebP ولا تحتاج اتصالاً بالشبكة. الحجم النهائي يتبع الأصول والاعتماديات الفعلية؛ لا تُضاف بيانات حشو لبلوغ رقم ثابت.
