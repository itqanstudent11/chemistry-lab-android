# تقرير التحقق — 4.0.0

تاريخ التحقق: 11 نوفمبر 2026. المصدر الأساس: `itqanstudent11/chemistry-lab-android`، الفرع `native-v1`، الالتزام `84e6822`. رُوجع أيضًا README وكود نسخة WebView التاريخية على `main` عند `a8cd66a`؛ الفروق غير المنقولة موثقة في مصفوفة النطاق. يتضمن مجلد `source` في الحزمة التغييرات الكاملة؛ لم تُرفع تغييرات أو إصدارات إلى GitHub أو متجر التطبيقات خلال هذه المهمة.

## البناء والملف المثبت

- اكتمل `testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest` بنجاح باستخدام JDK 17 وGradle 8.10.2 وAGP 8.6.1 وKotlin 2.0.21 وAndroid SDK 35.
- معرّف الحزمة: `org.arabicchemistry.lab.nativeedition`، الإصدار `4.0.0`، رقم البناء `2`، الحد الأدنى API 24، والمستهدف API 35.
- APK من نوع debug موقّع للتجربة؛ لا يتضمن التسليم مفتاح التوقيع الخاص، ولا يشكل مفتاح إصدار ثابتًا لمالك المشروع.
- تحقق التوقيع ومحاذاة ZIP إلى 16KB، وكذلك محاذاة جميع مقاطع ELF PT_LOAD للمكتبة الأصلية إلى 0x4000 في المعماريات الأربع. لم يُختبر التثبيت على جهاز فعلي ذي صفحات 16KB.
- لا يطلب التطبيق إذن الإنترنت أو الموقع أو التخزين. الإذن الداخلي `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` صادر عن AndroidX لحماية المستقبلات الديناميكية. النسخ الاحتياطي التلقائي معطّل.
- نتائج JVM وLint وبيانات APK الأساسية محفوظة في `docs/evidence`.

## الاختبارات المنفذة

- **8/8 اختبارات JVM ناجحة**، دون إخفاقات: حفظ الذرات والمتفاعل المحدد، حفظ المذاب، وحدات الغاز، اتزان الشحنة وpH، محتوى الذهب، الحدود والفيض والقيم غير المنتهية، والأرقام العربية والفارسية.
- **Lint: صفر أخطاء**. التحذيرات المتبقية تنبه إلى إصدارات أحدث للاعتمادات المثبتة؛ ليست اختبارات أداء أو أمان مستقلة.
- **فحوص المحتوى ناجحة:** 48 درسًا و144 سؤالًا لكل لغة؛ تطابق المعرّفات وترتيب الدروس والإجابات والمتطلبات السابقة وخلو شبكة المتطلبات من الدورات. ثبت تطابق ترتيب الدروس الـ42 الأصلية مع المصدر لترحيل التقدم.
- **العناصر: 118/118**، مع تحقق ترتيب الأعداد والرموز والمواقع واصطلاح الأوزان والأعداد الكتلية والحقول باللغتين.
- **الأدلة: 10 أدلة و41 موضوعًا لكل لغة**، مع تطابق الأقسام والمعرّفات والمراجع.
- **أداة التثبيت:** ستة سيناريوهات ناجحة تشمل ملفًا صحيحًا ومسافات في المسار وملفًا متغيرًا وبصمة مكررة أو لمسار مختلف وغياب سجل البصمات. لا يثبت هذا تنفيذ واجهة Termux وAndroid على هاتف فعلي.

## تشغيل Android

قيد التحقق على محاكي API 35؛ يجب استبدال هذه الفقرة بالنتيجة الفعلية قبل توليد حزمة التسليم.

## مصادر المحتوى وحدود التحقق

توسعت المادة باللغتين، مع مراجعة علمية أثناء التنفيذ وتحقق بنيوي مستقل. فحص المنهج 58 وصلة فريدة؛ استجاب 51 رابطًا بـHTTP 200، ورفضت سبعة روابط USGS الوصول الآلي بـ403. لا يُدّعى فحص هذه الملفات السبعة من داخلها. سجل مصادر أدلة الجيولوجيا والسلامة يوضح مواضع الاستناد إلى بيانات فهرسة وحدود الاستنتاج. الاستجابة HTTP 200 لا تثبت وحدها صحة كل ادعاء أو جودة الترجمة.

لا توجد بيانات عينات معتمدة هنا تثبت الذهب في كعيدنة وكشر وبني قيس، أو وجودًا محليًا موثقًا لكل عنصر في اليمن. لا توجد إحداثيات أو احتياطيات أو تراخيص محلية مختلقة. المحتوى لا يتضمن وصفات استخلاص خطرة أو تشغيل سيانيد أو رصاص.

## المتطلبات غير المكتملة

- مفتاح نشر إنتاجي ثابت وإدارة تحديثات عند مالك المشروع، والنشر إلى GitHub/المتجر.
- اختبار هواتف فعلية وإصدارات Android المتعددة، ومراجعة TalkBack والخطوط الكبيرة والأجهزة الضعيفة.
- محاكاة 3D أو حركية جزيئية أو تنبؤ بتفاعلات غير محددة مسبقًا؛ النماذج الحالية ثنائية الأبعاد ومثالية وحدودها ظاهرة.
- اكتمال موسوعة جامعية شاملة برسوم ومسائل أوسع، واعتماد علمي وترجمي مستقل.
- بيانات جيولوجية ومخبرية محلية أصلية، والتحقق من التراخيص اليمنية الحالية وخطط العمل الخاصة بالمواقع.
- مزامنة حسابات أو تصدير التقدم أو نقل التخزين إلى Room/DataStore؛ التخزين الحالي محلي باستخدام SharedPreferences. إزالة التطبيق تمحو التقدم والمفضلة والإعدادات.

توجد مصفوفة النطاق في `docs/REQUIREMENTS.md` وتفاصيل الاختبارات في `docs/TESTING.md`. بصمات `SHA256SUMS` للتحقق من تكامل الملفات، وليست توقيع ناشر مستقلًا.
