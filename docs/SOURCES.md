# سجل مصادر أدلة اليمن والمعادن والسلامة

تاريخ مراجعة الروابط والبيانات الببليوغرافية: 2026-11-11.

هذه الأدلة نصوص تعليمية مؤلفة وليست نسخًا من المراجع، ولا تمثل مراجعة ميدانية أو اعتمادًا من جيولوجي أو طبيب أو مهندس سلامة. تحتوي `guides_ar.json` و`guides_en.json` على عشرة أدلة متطابقة البنية، تضم 41 موضوعًا لكل لغة: ثلاثة أدلة جيولوجيا، وثلاثة للذهب والمعادن، وأربعة للسلامة. معرّفات الأدلة والموضوعات ثابتة بين اللغتين.

الأوصاف العامة لا تبيّن وحدات خرائط محلية أو إحداثيات أو تراخيص. المرجع المنشور في 1966 تاريخي ويرتبط بنطاق مسحه في ذلك الوقت؛ لا يعامل بوصفه تغطية حديثة تفصيلية لكل الجمهورية اليمنية.

**كعيدنة وكشر وبني قيس:** لم تتوفر لهذه النسخة ملفات عينات أولية ذات إحداثيات وسلسلة توثيق وشهادات مختبر يمكن التحقق منها. تظهر الحالة داخل التطبيق «غير متحقق محليًا». لا يثبت ذلك الوجود أو الغياب. لم تُنقل بيانات موقع آخر في حجة إلى هذه المناطق، ولم تُختلق درجات ذهب أو احتياطيات أو خرائط أهداف. أي إضافة مستقبلية تحتاج أصل التقرير وتاريخ الجهة المصدرة والخرائط ومقياسها ونظام الإحداثيات ووصف أخذ العينات ونتائج QA/QC ومراجعة مختص.

## المتطلبات غير المكتملة في هذا النطاق

- لا يوجد اعتماد علمي/مهني مستقل للنصوص أو الترجمة؛ يلزم تدقيق متخصص قبل اعتماد المحتوى منهجًا رسميًا.
- لا توجد قاعدة بيانات جيولوجية محلية حديثة شاملة أو خرائط GIS أو بيانات تحاليل موثقة لكل عنصر ومحافظة.
- لا توجد درجات خام أو موارد/احتياطيات موثقة لكعيدنة أو كشر أو بني قيس.
- لا توجد إجراءات تراخيص يمنية حديثة أو رسوم أو قائمة جهات اتصال طوارئ مؤكدة حسب المنطقة؛ يحتاج ذلك تحققًا محليًا.
- لا توجد إرشادات تشغيل استخلاص بالسيانيد أو الزئبق أو الرصاص أو وصفات معادلة/معالجة مخلفات. المحاكاة والحسابات تعليمية فقط.
