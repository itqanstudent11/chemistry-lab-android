# نطاق المنهج ومراجعة المحتوى

تتضمن هذه الحزمة **48 درسًا بالعربية ومقابلًا إنجليزيًا كاملًا لكل درس**، ضمن 16 قسمًا. تضم كل لغة 144 سؤال اختيار من متعدد (ثلاثة لكل درس)، مع أهداف تعلم ومتطلبات سابقة ومثال محلول وخلاصة وروابط للمراجعة.

| المستوى | الدروس |
| --- | ---: |
| تأسيسي / Foundation | 6 |
| متوسط / Intermediate | 9 |
| جامعي / University | 19 |
| تخصصي / Specialist | 14 |

المستويات تصف درجة تقديم الموضوع داخل التطبيق؛ لا تعادل اعتمادًا أكاديميًا أو شهادة مهنية. المحتوى **منهج تمهيدي منظم واسع الموضوعات، وليس موسوعة مكتملة أو بديلًا عن كتاب جامعي وتدريب مختبري معتمد**.

## ما أُنجز

- توسيع الدروس الأصلية الـ42 علميًا مع أمثلة عددية وشرح الافتراضات والحدود.
- إضافة ست وحدات: الذوبانية وحاصل الإذابة، الكيمياء النووية والإشعاع، المواد الصلبة والبلورات، عدم اليقين وإحصاء القياس، الكيمياء الخضراء ودورة الحياة، ومراجعة تربط العينة بالحساب والاستنتاج.
- ترجمة جميع حقول الدروس والأسئلة والشروح والأهداف والأقسام والمستويات إلى الإنجليزية. الروابط المرجعية مشتركة؛ لا تمثل النصوص ترجمة رسمية لهذه المراجع أو اعتمادًا منها.
- جعل الأسئلة العددية الأصلية مستقلة بمعطياتها، وتحسين البدائل المتكررة أو الغامضة، وتطابق الإجابات بين اللغتين.
- إضافة معرفات ثابتة `lesson-001` إلى `lesson-048` مع إبقاء ترتيب أول 42 درسًا كما كان لدعم ترحيل التقدم القديم. جميع روابط المتطلبات السابقة تشير إلى دروس سابقة موجودة دون دورات اعتماد.

## التغطية والحدود

يغطي المنهج المادة والذرة والجدول الدوري والترابط والمول والمحاليل والأحماض والاتزان والحركية والحرارة والكيمياء الكهربائية والتحليل والطيف والفصل والعضوية والبوليمرات والجزيئات الحيوية والتناسق والمعادن والمياه وجيولوجيا اليمن والتوعية المهنية.

المحاكاة وأمثلة الذهب حسابات ونماذج تعليمية. لا يتضمن المنهج وصفات استخلاص الذهب أو تشغيل أحواض السيانيد أو إضافة الرصاص أو معالجة مواد خطرة. لا يحول الحساب النظري مادة إلى خام اقتصادي أو نتيجة اختبار عملية. لا تمثل صفحات السلامة خطة طوارئ خاصة بموقع أو ترخيصًا أو تقييم تعرض مهنيًا.

بيانات عينات كعيدنة وكشر وبني قيس بمحافظة حجة ودرجاتها واحتياطياتها وإحداثيات رواسبها **غير متحققة في هذه الحزمة**. تذكر المواضع في إطار التوثيق المطلوب، ولا تنسب إليها نتائج مخبرية. غياب البيانات لا يثبت غياب العنصر. التقرير الوطني سياق عام وليس دليلًا لموقع محلي بعينه.

تظل المتطلبات التالية غير منجزة في المحتوى: كتاب موسوعي شامل بفروع متقدمة كاملة؛ مراجعة مستقلة واعتماد من كيميائيين وجيولوجيين ومختصي صحة مهنية؛ توثيق ميداني محلي لعينات اليمن؛ خرائط رواسب معتمدة؛ مختبر ثلاثي الأبعاد واقعي؛ ومسائل مقالية واشتقاقات رياضية ومشروعات مختبرية معتمدة. لا تدعي هذه النسخة تحققها.

## المراجع والتحقق

تستخدم الروابط فصولًا محددة من OpenStax، ومراجع Eurachem وLibreTexts وUSGS وNIOSH وATSDR وWHO وNIST وEPA وIFC. نصوص التطبيق مؤلفة للمشروع مع إحالات للمراجعة، وليست نقلًا رسميًا للمراجع.

في 2026-11-11 جرى طلب جميع **58 رابطًا مميزًا** في `sourceUrls`: أعاد **51 رابطًا HTTP 200**، وأعادت **7 روابط USGS HTTP 403** في البيئة الآلية. لا يعني رفض الوصول أن الروابط غير موجودة، لكنه يمنع ادعاء قراءة محتواها كاملًا أو التحقق المستقل منها هنا. يلزم مراجعتها يدويًا عند التوثيق المتخصص. الروابط ليست شرطًا لقراءة المحتوى المضمن دون اتصال.

التحقق الآلي شمل صحة JSON، وتطابق الحقول والمعرفات والإجابات وترتيب الدروس بين اللغتين، وثلاثة أسئلة لكل درس، وصلاحية فهارس الإجابات، وعدم وجود نص عربي غير مترجم في الملف الإنجليزي، وصحة إحالات المتطلبات السابقة. هذه فحوص بيانات وليست اعتمادًا علميًا مستقلاً.

## عقد البيانات

يحافظ `lessons.json` و`lessons_en.json` على الحقول القديمة `question/options/answer/explanation` باعتبارها نسخة من أول عنصر في `questions` لدعم الشيفرة السابقة. الحقول الجديدة: `id` و`objectives` و`prerequisites` و`questions` و`sourceUrls`. يحدد `answer` فهرس الخيار الصحيح ابتداءً من الصفر. يمثل `prerequisites` توجيهًا تعليميًا، ولا يلزم منه قفل الدرس.
